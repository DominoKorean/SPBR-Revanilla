# SPBR - Revanilla

SPBR - Revanilla is an add-on for SPBR that restores the textures and models differing from vanilla back to their original vanilla versions.

![Comparison image](https://cdn.modrinth.com/data/MPpKKeAK/images/a24216bd8c2840a3a15cee173d1ac3d5e3c2429a.jpeg)

> Due to updates to `pack.mcemeta` in version 1.21.9, the minimum supported range can now only be displayed as 1.20.1 ~ 1.21.+.  
> **This pack is compatible with all versions supported by SPBR.**

## Modified Elements

* Reverts the door item model back from 3D to the original.
  * Adds a PBR texture to the door item texture.
* Reverts the 3D model changes made to chains and lantern chains.
* Reverts the 3D model changes made to all types of rail blocks.
* Reverts the ladder back from a 3D model to the original.
* Reverts the mace back from a 3D model to the original.
  * Changes the mace’s PBR texture.
* Reverts the 3D model changes made to all types of bars.
* Restores mob eyes to no longer emit light.
* Reverts the changes made to the piston model.
* Reverts the changes made to the sugar cane model and texture.
* Reverts all tool item textures from albedo to the original.
* Reverts the panorama to the original.
* Reverts the mushroom to the original model.
* Reverts the eating animation to the original.
* Pickaxes, axes, hoes, shovels, and swords no longer use special textures when their durability is low.


> Not all modifications made by SPBR are clearly documented, so some changes might have been missed.  
> If you find any such cases, please report them on our [Discord server](https://discord.gg/D5zEJx3AFE).


## Respackopts Mod Support

This resource pack supports the following features through the Respackopts mod, which allows resource packs to add custom options.

- Restores the vanilla panorama appropriate for each Minecraft version.
- Provides the following two optional features:

* **Remove Armor Trim Glow**

  Removes the glowing effect from armor trims.

* **Remove Dyed Wolf Armor Glow**

  Adds a glowing effect to dyed wolf armor.

Originally, these two elements were not changed because they were considered to be SPBR's own interpretation of vanilla textures rather than inconsistencies with vanilla. Since adding Respackopts support, however, they are now available as optional features.

The three features above do not work in regular vanilla Minecraft. If you cannot use the mod, they can instead be applied as separate resource packs.

You can find the **Remove Armor Trim Glow** and **Remove Dyed Wolf Armor Glow** resource packs in the `Extra Resource Pack` folder inside the resource pack.

You can also find vanilla panorama resource packs for each Minecraft version in the `Panorama` folder inside `Extra Resource Pack`.
